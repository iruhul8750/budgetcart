# 🛒 BudgetCart

**Find the best budget products with honest reviews and exclusive deals**

BudgetCart is a fast, static affiliate marketing website built with Astro. It helps users discover high-quality budget products through honest reviews and curated recommendations.

## ✨ Features

- 🚀 **Blazing fast** - Built with Astro for near-instant load times
- 📝 **Easy content management** - Decap CMS admin dashboard at `/admin`
- 📊 **Analytics ready** - Google Analytics integration
- 🎨 **Beautiful design** - Tailwind CSS with custom branding
- 📱 **Fully responsive** - Works perfectly on all devices
- 🔍 **SEO optimized** - Auto-generated sitemaps and meta tags
- 🛒 **Affiliate ready** - Built-in affiliate link tracking
- 💰 **100% free** - Zero hosting costs with Cloudflare Pages

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/budgetcart.git
cd budgetcart

# Install dependencies
npm install

# Start development server
npm run dev
